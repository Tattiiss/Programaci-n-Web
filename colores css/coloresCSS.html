Colores

Hay más de 160 colores con nombre, que son compatibles modernos. Estos nombres se pueden usar directamente en CSS para aplicar colores a elementos sin especificar valores de algún modelo de color.

Por ejemplo:

  • Negro
  • Blanco
  • Salmon
  • Azul
  • Verde
